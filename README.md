# Netflix-Dashboard
# 🎬 Netflix Data Analysis & Interactive Dashboard – Power BI

## 📌 Project Overview

The **Netflix Data Analysis Dashboard** is an interactive and visually engaging **Power BI project** created to analyze and understand Netflix's content library. The dashboard transforms raw Netflix data into meaningful insights through interactive charts, KPIs, filters, and visualizations.

The main objective of this project is to provide a comprehensive overview of **Movies and TV Shows available on Netflix**, while analyzing important attributes such as **content type, release year, genre, rating, country, duration, and overall content growth**.

Using **Power BI, Power Query, and DAX**, the raw dataset was cleaned, transformed, analyzed, and converted into an easy-to-understand interactive dashboard.

---

## 🎯 Project Objectives

The primary objectives of this dashboard are:

* To analyze the overall Netflix content library.
* To identify the total number of Movies and TV Shows.
* To compare Movies and TV Shows based on their quantity.
* To analyze how Netflix content has changed over the years.
* To identify the most common and popular content genres.
* To analyze content distribution across different countries.
* To understand the distribution of content based on ratings.
* To analyze movie duration and TV Show seasons.
* To identify trends in Netflix content production and releases.
* To provide an interactive platform for exploring Netflix data.

## 📈 Key Analysis Performed

### 1. Movies vs TV Shows Analysis

The dashboard provides a clear comparison between **Movies and TV Shows** available on Netflix.

This analysis helps understand:

* Total Movies available
* Total TV Shows available
* Percentage contribution of each content type
* Overall content-type distribution

Interactive charts make the comparison simple and easy to understand.

---

### 2. Content Growth Over the Years

A year-wise analysis is included to understand how Netflix's content library has evolved over time.

This visualization helps identify:

* Years with the highest number of releases
* Growth of Netflix content
* Changes in content production trends
* Historical distribution of Movies and TV Shows

The trend analysis provides a better understanding of Netflix's expansion in terms of available content.

---

### 3. Genre Analysis

The dashboard analyzes different Netflix genres and categories.

It helps identify:

* Most common genres
* Genre-wise content distribution
* Movies and TV Shows by genre
* Content categories with higher representation

Users can interact with the dashboard to explore specific genres and their associated content.

---

### 4. Country-wise Content Analysis

A geographical analysis is used to understand the distribution of Netflix content across different countries.

This analysis provides insights into:

* Countries producing the most content
* Country-wise content contribution
* International content distribution
* Regional differences in Netflix's content library

A map visualization can be used to provide an easy geographical representation of the data.

---

### 5. Ratings Analysis

The dashboard also analyzes Netflix content based on different audience ratings.

It provides insights into:

* Most common ratings
* Rating-wise content distribution
* Movies and TV Shows by rating
* Comparison of different rating categories

This helps users understand the type of content represented across different rating classifications.

---

### 6. Movie Duration Analysis

Movie duration is analyzed to understand the typical length of Netflix movies.

The dashboard can provide information such as:

* Average movie duration
* Minimum and maximum duration
* Duration distribution
* Comparison of movie lengths

This helps in understanding the viewing-time characteristics of Netflix's movie library.

---

### 7. TV Show Season Analysis

For TV Shows, the dashboard analyzes the number of seasons.

* TV Shows with multiple seasons

## 🧹 Data Cleaning & Transformation

Before creating the dashboard, the raw Netflix dataset was processed using **Power Query**.

The data preparation process included:

* Removing duplicate records
* Handling missing values
* Cleaning text fields
* Standardizing categorical values
* Splitting columns where required
* Transforming date and year fields
* Formatting numerical columns
* Handling blank and null values
* Creating required calculated columns
* Preparing the dataset for visualization

This data-cleaning process helped improve the accuracy and usability of the dashboard.

---

## 🧮 DAX & Data Analysis

**DAX (Data Analysis Expressions)** was used to create calculated measures and perform different analytical calculations.

Examples of analysis include:

* Total content count
* Movie count
* TV Show count
* Percentage calculations
* Average duration
* Year-wise calculations
* Category-wise analysis
* Dynamic KPI calculations

DAX measures allow the dashboard to update dynamically when users apply filters or interact with different visualizations.
